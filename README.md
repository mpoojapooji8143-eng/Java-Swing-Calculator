# 🧮 Java Swing Calculator

A simple and user-friendly calculator application developed using Java Swing. This project demonstrates how to build a graphical user interface (GUI) in Java and perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 📌 Project Overview

The Java Swing Calculator is a desktop-based application that allows users to perform basic mathematical calculations through an interactive graphical interface. The calculator provides buttons for numbers and arithmetic operators, enabling users to input values easily and view results instantly.

This project was developed as part of learning Java programming and GUI development. It helps in understanding event handling, Swing components, and object-oriented programming concepts in Java.

## ✨ Features

* Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
* Clear (C) button to reset calculations
* User-friendly graphical interface
* Organized button layout for easy interaction
* Fast and responsive calculations

## 🛠 Technologies Used

* Java
* Java Swing
* Eclipse IDE

## ▶ How to Run the Project

1. Download or clone the repository.
2. Open the project using Eclipse IDE or any Java-supported IDE.
3. Compile and run the `ProCalculator.java` file.
4. The calculator interface will appear and you can start performing calculations.
